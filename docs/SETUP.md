# دليل الإعداد (مرة وحدة بس)

يشرح هذا الدليل كيف تشغّل المكتبة من الصفر. ما يحتاج خبرة برمجة، بس امشِ مع الخطوات بالترتيب.
الوقت المتوقع: تقريباً ٣٠ دقيقة.

---

## ١. حساب تيليجرام ثاني (موصى فيه بقوة)

النظام يقرأ القنوات بحساب تيليجرام، وأي أحد عنده "جلسة" هذا الحساب يقدر يتحكم فيه بالكامل.
عشان كذا:

1. سوِّ حساب تيليجرام جديد برقم ثاني.
2. اشترك فيه بالقنوات الست، **وبس**.
3. خلّك مشترك فيها بعد من حسابك الأساسي، عشان زر **Open in Telegram** يفتح لك المنشور على جوالك.

> تقدر تستخدم حسابك الأساسي إذا تبي، بس لو تسرّبت الجلسة، رسايلك الخاصة كلها تكون مكشوفة.

## ٢. مفاتيح تيليجرام (api_id و api_hash)

1. افتح https://my.telegram.org وسجّل دخول **بالحساب الثاني**.
2. ادخل **API development tools**.
3. عبِّ النموذج بأي اسم، مثلاً `model library`، واختر Platform: `Desktop`.
4. انسخ `api_id` و `api_hash`.

## ٣. إنشاء جلسة الدخول على جهازك (ويندوز)

1. نزّل Python من https://www.python.org/downloads/ ، ووقت التثبيت **فعّل خيار "Add python.exe to PATH"**.
2. نزّل هذا المستودع: من صفحة GitHub اضغط **Code ← Download ZIP**، وفك الضغط.
3. افتح **PowerShell** داخل المجلد. أسهل طريقة: افتح المجلد، اكتب `powershell` في شريط العنوان، واضغط Enter.
4. نفّذ:
   ```powershell
   py -m pip install telethon
   py scripts\login.py
   ```
5. أدخل `api_id` و `api_hash`، وبعدها رقم الجوال (بالصيغة الدولية مثل `+9665…`)، وبعدها الكود اللي يوصلك على تيليجرام.
6. البرنامج يطبع لك شيئين:
   - **قائمة القنوات**، وجنب كل قناة القيمة اللي تستخدمها.
   - **TG_SESSION**: سطر طويل جداً. انسخه كامل. **لا ترسله لأي أحد ولا تحطه إلا في GitHub Secrets.**

## ٤. مفتاح Claude API

1. افتح https://console.anthropic.com وسجّل.
2. أضف رصيد بسيط من **Billing**. خمسة دولار تكفي لآلاف الموديلات.
3. من **API Keys** سوِّ مفتاح جديد وانسخه.

## ٥. إضافة الأسرار في GitHub

في صفحة المستودع: **Settings ← Secrets and variables ← Actions ← New repository secret**.
أضف كل واحد من هذول:

| الاسم | القيمة |
|---|---|
| `TG_API_ID` | الرقم من الخطوة ٢ |
| `TG_API_HASH` | النص من الخطوة ٢ |
| `TG_SESSION` | السطر الطويل من الخطوة ٣ |
| `TG_CHANNELS` | قيم القنوات من الخطوة ٣، كل وحدة في سطر |
| `ANTHROPIC_API_KEY` | المفتاح من الخطوة ٤ |
| `SITE_PASSWORD` | كلمة سر قوية تختارها لفتح الموقع |
| `THUMB_SECRET` | أي نص عشوائي طويل (٣٠ حرف أو أكثر)، ما تحتاج تحفظه |

> ⚠️ **لا تنسى `SITE_PASSWORD`**. كل البيانات مشفرة فيها، ولو ضاعت ما فيه طريقة لاسترجاعها، وتضطر تبدأ المكتبة من جديد.

## ٦. تفعيل GitHub Pages

1. **Settings ← Pages**.
2. تحت **Build and deployment ← Source**، اختر **GitHub Actions**.

## ٧. أول تشغيل

1. ادخل تبويب **Actions**. إذا طلب منك تفعيل الـ workflows، فعّلها.
2. اختر **Sync library** من القائمة، واضغط **Run workflow**، واختر `sync`.
3. أول مرة يسحب الأرشيف كامل. إذا القنوات كبيرة، ممكن يتوزع الشغل على أكثر من تشغيل، كل تشغيل مدته ٢٠ دقيقة. ويكمّل تلقائياً كل ٣٠ دقيقة.
4. التصنيف: لو فيه موديلات كثيرة، تتصنف دفعة وحدة عن طريق Batch API (أرخص بالنص)، والنتيجة تجهز عادة خلال ساعة أو أقل وتظهر في التشغيل اللي بعده.

## ٨. فتح الموقع

الرابط يكون بالشكل: `https://<اسم-حسابك>.github.io/<اسم-المستودع>/`
وتلقاه بعد في **Settings ← Pages**.

أدخل `SITE_PASSWORD` وفعّل **Remember on this device** عشان ما يسألك كل مرة. وعلى أي جهاز ثاني (جوال، لابتوب) تسوي نفس الشي مرة وحدة.

## تعديلات لاحقة

### إضافة قناة أو حذفها
عدّل السر `TG_CHANNELS` (Update secret). القناة الجديدة يُسحب أرشيفها كامل في التشغيل الجاي. والقناة المحذوفة تختفي من الموقع، بس بياناتها تظل محفوظة لو رجعتها.

### تعديل التصنيفات
1. عدّل الملف `taxonomy.yml` في المستودع، وارفع رقم `version` بواحد.
2. شغّل **Sync library** يدوياً واختر `reclassify`.

### تغيير كلمة سر الموقع
1. سوِّ سر جديد اسمه `SITE_PASSWORD_OLD` وحط فيه كلمة السر **القديمة**.
2. غيّر `SITE_PASSWORD` للكلمة الجديدة.
3. شغّل **Sync library** يدوياً (`rebuild`). البيانات كلها تتشفّر من جديد بالكلمة الجديدة.
4. احذف `SITE_PASSWORD_OLD`.

### تغيير موديل التصنيف
الافتراضي `claude-haiku-5-5`، وهو سريع ورخيص. لو تبي دقة أعلى:
**Settings ← Secrets and variables ← Actions ← Variables ← New variable**
بالاسم `CLASSIFIER_MODEL` والقيمة `claude-sonnet-5-5`.

### إذا وقف التحديث التلقائي
GitHub يوقف الجدولة إذا ما صار أي نشاط على المستودع ٦٠ يوم. هذا نادر هنا، لأن كل موديل جديد يسوي commit. بس لو صار: **Actions ← Sync library ← Enable workflow**.

### الجلسة انتهت
لو سجّلت خروج من كل الأجهزة في الحساب الثاني، أعد الخطوة ٣ وحدّث السر `TG_SESSION`.
